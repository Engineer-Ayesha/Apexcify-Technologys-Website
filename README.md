# 🌐 Apexcify Technologies Website

A modern and responsive business website built using **HTML, CSS, and JavaScript**. The website presents Apexcify Technologies' services, portfolio, company information, and contact details through a clean, professional, and user-friendly interface.

## 🚀 Features

- Responsive design for desktop, tablet, and mobile
- Fixed navigation bar with smooth scrolling
- Mobile navigation menu
- Animated sections on scroll
- Professional Services section
- Portfolio showcase
- Contact section with email, LinkedIn, and WhatsApp
- Modern business UI

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Font Awesome

## 🧠 Problem Solving Approach

- Built a fully responsive business website using Flexbox and media queries.
- Implemented a mobile navigation menu for smaller devices.
- Added scroll-based animations to improve user engagement.
- Organized the layout into reusable sections for maintainability.
- Focused on accessibility, performance, and a professional user experience.
